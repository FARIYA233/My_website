# My Website

A simple, responsive personal website built with **HTML5, CSS3, and vanilla JavaScript**.

The project presents personal information, skills, interests, and basic web development content through a clean and user-friendly interface.

The website is intentionally lightweight and framework-free. It does not require a backend server, database, frontend framework, or API key.

## Live Demo

**GitHub Repository:**
https://github.com/FARIYA233/My_website

## Features

### Personal Website

The website provides a simple personal profile interface that can be used to present:

* Personal information
* Educational background
* Skills
* Interests
* Contact information
* Basic web development information

### Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile devices

The layout adapts to smaller screens to provide a better user experience.

### Clean User Interface

The project focuses on:

* Simple and clean design
* Organized content
* Easy navigation
* Readable typography
* Responsive layout
* User-friendly structure

### JavaScript Functionality

JavaScript is used to add basic interactive functionality to the website.

The JavaScript code is separated from the HTML structure to keep the project organized and easy to understand.

## Technology Stack

| Technology | Purpose                                        |
| ---------- | ---------------------------------------------- |
| HTML5      | Page structure and content                     |
| CSS3       | Styling, layout, and responsive design         |
| JavaScript | Interactive functionality and DOM manipulation |

No frontend framework or external JavaScript library is required.

There is also no backend server or database.

## How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/FARIYA233/My_website.git
```

### 2. Open the Project Folder

```bash
cd My_website
```

### 3. Run the Project

Open `index.html` in any modern web browser.

For the best development experience, the project can also be opened in **Visual Studio Code** using a local development extension such as **Live Server**.
